# Claude Code conventions for this repo

## Git
- Branch names describe the change: `feature/<short-description>` (lowercase, hyphens), e.g. `feature/tour-record-locators`. Bug fixes use `fix/<short-description>`. Never use auto-generated names like `ccr-xxxx`.
- Run `npm run check` before pushing.

## Writing
- Write instructions and config for Claude Code (this file, `.claude/`) in English.
